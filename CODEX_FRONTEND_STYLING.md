# FRONTEND STYLING REQUIREMENTS (MANDATORY)

1. DO NOT create or use SCSS (.scss) or Sass anywhere in the project.
2. DO NOT introduce any Sass compiler or build pipeline.
3. Use ONLY standard CSS (.css) files.
4. Every template must have a corresponding CSS file when appropriate.
5. Organize CSS under `static/css/` using modular files.
6. Use CSS Variables, CSS Grid, Flexbox, responsive media queries, BEM or another consistent naming convention, and semantic accessible HTML5.
7. Keep JavaScript separate from styling.
8. Do not place large inline styles in templates.
9. Build a professional institutional trading UI with a consistent design system.
10. Ensure all new frontend code integrates with Django static files using HTML, CSS, and JavaScript only.
