## Cryptocurrency SVGs

The SVG files in `crypto/` are copied from [Simple Icons](https://github.com/simple-icons/simple-icons). The upstream repository uses CC0-1.0; upstream also cautions that individual icon licensing can vary and that copyright dedication does not waive trademark rights. The local registry records each upstream source. Marks are used only to identify underlying crypto instruments, not as AlgoBot or Deriv branding. Confirm relevant brand/trademark requirements before using these marks in promotional materials.
