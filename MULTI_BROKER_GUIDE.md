# Multi-Broker Guide

Users can connect one broker, multiple brokers, and multiple accounts per broker. The Broker Manager tracks health, latency, and connection status for each broker and account. The trading terminal displays Active Broker, Connected Account, Broker Status, Execution Latency, and Connection Health while keeping order tickets, strategies, risk controls, and analytics platform-wide.

Supported production adapters: Deriv and Paper Trading. Scaffold adapters: Binance, Bybit, OANDA, Interactive Brokers, MetaTrader Gateway, DXTrade, cTrader, Alpaca, Forex.com, Pepperstone, IC Markets, and Exness.
