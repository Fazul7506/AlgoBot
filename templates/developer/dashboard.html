Sample Request

Illustrative cURL request using the registered API key endpoint.

BASH
Terminal
curl -X GET "{{ request.scheme }}://{{ request.get_host }}/api/developer/keys/" \
  -H "X-API-Key: YOUR_API_KEY" \
  -H "X-API-Secret: YOUR_API_SECRET" \
  -H "Accept: application/json"

{
  "status": "success",
  "data": []
}
