AlgoBot Enterprise · Operations

Broker Reconciliation

Investigate differences between AlgoBot's local execution records and broker-authoritative state without automatically mutating trades.

Safe investigation

Open discrepancies are evidence for an operator to review. Reviewing an event does not alter the order, position, broker response, or account balance.

Broker authority

Broker state remains authoritative for execution. A missing item in a limited broker snapshot is treated as a discrepancy, not proof that the trade never existed.

Resolution rule

Do not create, delete, close, or rewrite a trade from this screen. Corrective actions must go through the normal execution and audit paths.

Event lifecycle

  1. Open — discrepancy detected during synchronization.
  2. Investigate — inspect broker reference, symbol, account and captured details.
  3. Reviewed — operator acknowledges the event; underlying trading state remains unchanged.

API investigation

The authenticated execution API exposes reconciliation events with user/account scoping and status filtering.

/api/execution/reconciliation/events/

?status=open can be used to focus on unresolved events.
