Public support

Contact AlgoBot

Use this page as the public support entry point for AlgoBot. For faster handling, identify the category of your request: technical support, privacy, Google user data, data deletion, or broker connection.

Privacy and Google user-data requests

If your request concerns Google account information, Gmail authorization, OAuth permissions or deletion of connected notification data, state that clearly in your support request. We will use the information necessary to identify the relevant account and process the request securely.

Account and broker support

For broker connection, account, execution or platform issues, include the affected feature and approximate time of the issue. Never send passwords, API secrets, access tokens, Telegram bot tokens or Google client secrets through a support request.

Data deletion

For a formal deletion request, use the dedicated Data Deletion Request page. The request flow explains what can be deleted and what records may need to be retained for security or legal reasons.
