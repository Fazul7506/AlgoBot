# Indicator Library

Supported indicators include SMA, EMA, WMA, VWMA, MACD, RSI, Stochastic, ADX, ATR, CCI, ROC, Momentum, Bollinger Bands, Keltner Channels, Donchian Channels, Parabolic SAR, Ichimoku Cloud, Awesome Oscillator, Williams %R, MFI, OBV, Pivot Points, SuperTrend, Heikin Ashi, and ZigZag.
