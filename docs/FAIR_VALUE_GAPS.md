# Fair Value Gaps

Phase 8 Smart Money Concepts module documentation. The engine is deterministic, read-only with respect to trade execution, and exposes institutional market intelligence through `apps.smart_money`.

## Capabilities

- Detects market structure, liquidity, order blocks, fair value gaps, sessions, kill zones, institutional bias, narrative, and confluence.
- Provides API-only intelligence for strategies, AI models, dashboards, alerts, and discretionary review.
- Does not execute trades directly.
